# CrickBox Pro - Turf & Corporate Cricket Tournament Manager

CrickBox Pro is an elite, production-ready web application designed for organizing turf and corporate cricket tournaments with automated fixture scheduling, live NRR calculation, Supabase cloud synchronization, and Razorpay subscription integration.

## 🚀 Features
- **Team & Roster Management**: Easily add and manage participating teams.
- **Automated Fixture Generator**: Generates round-robin schedules instantly.
- **Live Points Table & NRR Engine**: Calculates Net Run Rate and standings dynamically.
- **Live Stream Hub & Match Clips**: Interactive stream integration and highlights gallery.
- **Razorpay Integration**: Seamless ₹999 Pro Pass checkout workflow.
- **Supabase Cloud Sync**: Real-time multi-device score updates.

## 📦 Deployment Instructions (Vercel)
1. Push this folder to a GitHub repository.
2. Import the repository into [Vercel](https://vercel.com).
3. Deploy instantly with zero configuration required!
